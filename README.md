###  Hardware Prototyping & IoT Systems by Atahan Güney
Alongside software tools, I actively develop physical embedded systems by combining hands-on hardware prototyping (soldering, multimeter diagnostics, breadboard circuit stabilization, and actuator control) with embedded programming:

* **Computer Vision Gesture & Servo Control System:** Developed an interactive hardware-software bridge using **Python** and **OpenCV** to track real-time hand gestures via webcam. Configured UART serial communication to translate visual coordinates into precise physical servo motor commands on an **Arduino** with reliable signal transmission and hardware-level breadboard debugging.
* **IoT Smart BLE Notification Display:** Engineered an **ESP32** wireless integration (using MicroPython & BLE) to receive and push live mobile notifications directly onto an **SSD1306 OLED** screen via I2C.
* **IoT Telegram-Controlled Hardware & Environmental Monitoring System:** Built a **Raspberry Pi Pico 2W / Raspberry Pi** IoT system featuring a Telegram Bot API integration that translates remote text commands into physical Morse code audio/switching via a relay module. Includes a real-time data logging and visualization script that monitors onboard CPU temperature against ambient environmental data to generate comparative thermal graphs.
